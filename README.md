# SUDOKU – Play & Create

A clean, responsive educational Sudoku website built with HTML, CSS, and JavaScript.

## Features
- **Play Sudoku**: Easy, Medium, and Hard difficulty levels with unique-solution verification, timer, pause/resume, mistake counter, 3 hints, and keyboard/mouse controls.
- **Create Your Own Sudoku**: Build puzzles manually, validate row/column/3×3 box rules and unique-solution constraints, save locally, export/share, and play custom puzzles with locked starting clues.
- **How to Play Sudoku & Beginner Guide**: Clear rules with visual mini-diagrams and an interactive 7-step beginner walkthrough.
